# Suporte

Antes de pedir ajuda, consulte o [README](README.md), pesquise as
[issues](https://github.com/Araendy-Aratyba/tesa/issues) e verifique se o problema
é causado por uma configuração local.

- Use as [discussões](https://github.com/Araendy-Aratyba/tesa/discussions) para
  dúvidas de uso, ideias iniciais e conversas abertas.
- Abra uma issue pelo formulário apropriado para bugs reproduzíveis ou propostas
  já estruturadas.
- Siga a [Política de Segurança](SECURITY.md) para vulnerabilidades; nunca
  publique credenciais ou dados sensíveis.

O projeto é mantido por voluntários. Não há garantia de prazo de resposta, mas
relatos claros, reproduzíveis e respeitosos facilitam a colaboração.
